# 🔮 赛博解梦师

> 一个娱乐型解梦工具，结合荣格心理学与网络热梗，将梦境翻译成有趣、有启发、可分享的报告。

[![Skill Status](https://img.shields.io/badge/Skill-v1.1-blue.svg)](https://github.com/kasonTz/trae-skill)

---

## ✨ 功能特点

- 🔮 **双轨解读**：荣格心理学 + 网络热梗，用专业视角说人话
- 🤖 **智能追问**：描述太简短？自动引导补充细节
- 🎁 **赛博彩蛋**：动态生成的趣味标签，截图分享超有梗
- 🛡️ **安全边界**：积极健康导向，只给正能量（但不鸡汤）
- 📱 **移动端优化**：卡片式排版，截图分享超好看

## 🚀 快速开始

### 安装步骤

1. 下载本仓库中的 `SKILL.md` 文件
2. 导入到你的 AI 工具中
3. 直接输入梦境描述即可触发

> 💡 通用提示：大多数平台都支持直接导入 `.md` 文件的 Skill，具体请参考各平台的官方文档。

### 使用方式

```
我昨晚做了一个梦，梦见自己回到了高中教室，牙齿掉了...
```

就是这么简单！不需要特殊指令，直接说"我梦见..."就行。

## 📋 报告结构

每份报告包含 **5 个板块**，总字数约 500-800 字：

| 板块 | 说明 |
|------|------|
| 🌙 梦境速览 | 一句话文艺+幽默地概括梦境 |
| 🔮 赛博解码 | 关键符号的荣格视角 + 赛博翻译双解读 |
| 🧠 心理镜像 | 梦境映射到当前心理状态的分析 |
| 💊 赛博处方 | 2-3条轻松可执行的小建议 |
| 🥚 赛博彩蛋 | 动态生成的趣味标签/金句 |

## ⚙️ 设计理念

**风格定位**：神秘不玄乎，专业不说教，像懂心理学又爱玩梗的朋友

**座右铭**：「梦里不知身是客，醒来已是解梦人」

**目标场景**：
- 深夜做了奇怪的梦，想找点乐子
- 和朋友分享梦境，收获一句"扎心"的解读
- 想通过梦境更好地了解自己
